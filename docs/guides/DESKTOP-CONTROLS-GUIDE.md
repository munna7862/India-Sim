# Desktop Controls & Interaction Guide

- **Product:** Rashtra: Sovereign Republic (Windows Desktop Remake)
- **Version:** 1.0.0 (Release)
- **Primary Input:** Mouse & Keyboard

---

## 1. Mouse Navigation

| Action | Control | Description |
|---|---|---|
| Select Country | Left Mouse Click | Clicks on any country polygon on the interactive vector world map to select it and open the foreign geopolitical profile drawer. |
| Pan Map Viewport | Left Mouse Drag / Middle Drag | Click and drag across the map canvas to pan the camera across continents. Camera position is clamped to geographical bounds. |
| Zoom Viewport | Mouse Scroll Wheel / Pinch | Scroll up to zoom in, scroll down to zoom out. Zooming is anchored to cursor location and clamped between 0.5x and 5.0x scale. |
| Hover Tooltip | Mouse Hover | Hover over any sovereign nation to display a tooltip card with capital city, population, GDP, relations, and geopolitical stance. |
| Button / Tab Actions | Left Mouse Click | Navigate between Ministries, Presidential Tasks, National Budget, Armed Forces, and Foreign Affairs. |

---

## 2. Global Keyboard Shortcuts

| Shortcut Key | Function | Description |
|---|---|---|
| `Space` | Pause / Resume Time | Toggles simulation clock between paused (0x) and active running state. |
| `1` | 1x Speed | Sets simulation clock to normal 1x speed (~1 second per in-game day). |
| `2` | 2x Speed | Sets simulation clock to double 2x speed (~0.5 seconds per in-game day). |
| `3` | 3x Speed | Sets simulation clock to high 3x speed (~0.25 seconds per in-game day). |
| `F1` | World Map | Centers and focuses the interactive geopolitical world map canvas. |
| `F2` | Government & Cabinet | Opens the Ministerial Cabinet and State Ideology dashboard. |
| `F3` | Presidential Tasks | Opens the Presidential Tasks & Objectives panel. |
| `F4` | Economy & Budget | Opens the National Budget, Tax Sliders, Loans, and Facility Construction panel. |
| `F5` | QuickSave | Instantly captures authoritative game state to the dedicated QuickSave slot. |
| `F6` | Diplomacy & Treaties | Opens the Foreign Bilateral Relations and Trade Contracts drawer. |
| `F7` | Military & Armed Forces | Opens the Armed Forces Unit Inventory, Recruitment, and Drills panel. |
| `F8` | Internal Security | Opens Presidential Protection, Anti-Corruption, and Counter-Terrorism tools. |
| `F9` | QuickLoad | Restores game state from the QuickSave slot. |
| `F10` | Settings Menu | Opens display resolution, volume, UI scaling, and map theme palette options. |
| `Escape` | Pause / Dismiss | Closes active modal dialogs, drawers, or opens the Pause Menu. |

---

## 3. Map Themes & Visual Palettes

Players can toggle between 3 curated high-contrast desktop map palettes via Settings (`F10`) or the map palette button:

1. **Tactical Dark (Default):** Sleek high-tech dark theme featuring deep obsidian oceans (`#0B0F19`), slate land masses, and glowing cyan borders.
2. **Strategic Navy:** Classic command-room aesthetic with midnight navy seas (`#0A192F`), steel-blue nations, and crisp silver borders.
3. **Amber Cartographic:** Retro-tactical warmth with dark sepia oceans (`#1A1612`), warm parchment territories, and amber accents.
