# ADR-001: Desktop Engine Candidate

- Status: Proposed; validate in Sprint 00-03.
- Decision candidate: Godot 4 .NET with C# for a Windows desktop strategy game.
- Rationale: 2D map/UI support, optional 3D presentation, C# domain modelling and desktop packaging.
- Constraint: gameplay rules remain in a plain .NET domain project wherever practical.
- Revisit if the prototype fails a concrete requirement or the pinned engine/SDK combination is unsuitable.
