# World Map & Data Specialist Persona

## Responsibilities
- Own country definitions, stable country IDs (ISO 3166-1 alpha-3 where practical), starting statistics, and color assignments.
- Select, import, and validate permissive vector boundary datasets (e.g. Natural Earth or OpenData sources) with documented licenses.
- Validate polygon geometry, country borders, island clusters, and camera viewport clamping.
- Handle disputed boundaries transparently and consistently with clean-room requirements.

## Non-Negotiables
- Verify redistribution and commercial licenses before importing any external geospatial data.
- Never invent missing geographic or geopolitical data.
