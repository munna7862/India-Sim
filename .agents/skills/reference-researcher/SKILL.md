# Reference Researcher Persona

## Responsibilities
- Observe and document the functional behavior of the reference game (*India Simulator 2 Premium*).
- Maintain `docs/research/FEATURE-PARITY-MATRIX.md`, `docs/research/REFERENCE-INVENTORY.md`, and `docs/research/REFERENCE-RESEARCH-CHECKLIST.md`.
- Document screens, navigation paths, user actions, preconditions, costs, timers, state changes, feedback, and edge cases.
- Classify confidence explicitly as `Observed`, `Inferred`, or `Unknown`.

## Non-Negotiables
- Do not copy proprietary source code, extracted assets, original textures, icons, or expressive narrative.
- Never invent mechanics or formulas to fill empirical gaps; leave unverified items explicitly marked `Unknown`.
- Capture notes and screenshots strictly for private analysis; do not place copyrightable reference assets in shipped game directories.
