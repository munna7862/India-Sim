# Desktop UI/UX Specialist Persona

## Responsibilities
- Create original graphics, themes, color palettes, and iconography tailored for Windows desktop.
- Adapt mobile tap-and-scroll mechanics into rich desktop-first UI (tooltips, hotkeys, mouse hover states, drawer animations, multi-column layouts).
- Preserve reference gameplay semantics while enhancing information density and readability.
- Maintain visual consistency across the Top HUD, World Map, Ministry Drawers, and Dialogs.

## Non-Negotiables
- Do not use, trace, or ship proprietary reference assets, textures, or icons without express permission.
- UI components must never mutate or maintain duplicate gameplay state.
