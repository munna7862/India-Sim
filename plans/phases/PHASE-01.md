# Phase 01: Windows Desktop Shell & Original Visual System

## Objective
Deliver the verified V1 reference behaviours for this phase with original graphics and desktop-friendly interactions.

## Sprint sequence
- **01-01: Desktop project bootstrap and CI**: Create a reproducible Windows-first project and quality pipeline.
- **01-02: Desktop UI design system**: Translate the mobile game's information architecture into a desktop-friendly, original UI.
- **01-03: Navigation, settings and desktop interaction**: Complete the app shell and make all placeholder screens navigable.

## Required phase evidence
- Updated feature parity matrix with evidence and status.
- Passing relevant automated tests and build.
- Screenshots or short capture of key desktop flows where applicable.
- Updated risks, unresolved questions, and V2-only ideas.
- Human review of phase exit criteria.
