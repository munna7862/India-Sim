# Phase 02: World Map, Country Selection & Scenario Start

## Objective
Deliver the verified V1 reference behaviours for this phase with original graphics and desktop-friendly interactions.

## Sprint sequence
- **02-01: Country registry and start-state data**: Create the data model required to start a game as an available country.
- **02-02: World map interaction and selection**: Build a readable map with country selection, hover and inspection.
- **02-03: New game setup and initial world state**: Implement the scenario start path and ensure repeatable initialization.

## Required phase evidence
- Updated feature parity matrix with evidence and status.
- Passing relevant automated tests and build.
- Screenshots or short capture of key desktop flows where applicable.
- Updated risks, unresolved questions, and V2-only ideas.
- Human review of phase exit criteria.
