# Phase 00: Reference Research, Scope & Clean-Room Design

## Objective
Deliver the verified V1 reference behaviours for this phase with original graphics and desktop-friendly interactions.

## Sprint sequence
- **00-01: Build the reference feature inventory**: Turn the original game into an observable, testable feature list without copying its code or assets.
- **00-02: Clean-room design and legal boundaries**: Define what will be recreated functionally and what must be independently designed.
- **00-03: V1 acceptance criteria and technical spike**: Lock the faithful-remake target and prove the desktop technology stack.

## Required phase evidence
- Updated feature parity matrix with evidence and status.
- Passing relevant automated tests and build.
- Screenshots or short capture of key desktop flows where applicable.
- Updated risks, unresolved questions, and V2-only ideas.
- Human review of phase exit criteria.
